Sinister Lab

STUB - this page is a work in progress. Asset references and texture lists will be filled in as the environment mod is built out.

The Sinister Lab is a terminal mission environment. It contains a scifi lab environment mesh set that is distinct from the forested micro-biomes found within the same region. This page documents the relevant .upk packages and the texture assets they reference.

Region

Sinister Lab terminal mission region (level 35).

UPK Packages

PackageContents
SCS__DailyGSinisterLabRegionL35_SF.upk Contains the mesh and texture assets referenced by the Sinister Lab terminal mission. This is the primary package for the scifi lab environment mesh set.

Environment Groups

Scifi Lab

The scifi lab environment mesh set. Lab interiors, equipment, and techno-logical structures that differentiate this area from the surrounding biomes.

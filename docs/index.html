Marvel Heroes Omega Art Mods

A collection of client-side texture and icon replacement mods for Marvel Heroes Omega

DOWNLOAD ALL | GITHUB

ITEM

Dark Runes

Runes of Asgardian magic carved into basalt stone. Dark-themed replacements for rune item icons.

Uru Reforged

Nidavellir dwarven Uru metal forged by Asgardian smiths into magic armor.

Artifacts Armor

Ancient Artifacts of powers cosmic, awakened Armor enchanted by the techno-logical.

Battleforged Baubles

Bionically built Baubles forged in Battles from the beyond.

UI

No Glass Overlay

Removes the "glass" style bevel emboss on item and power icons.

Power Not Ready Hidden

A locale string replacement that hides "Power not ready" red text and similar failure messages.

SFX

Sound Silencer

silences specific sounds by editing the game's audio .pck files. preset includes all "cant do that" phrases

ENV

Sinister Lab

The Sinister Lab darkened and non-reflective with wide beveled panel lines

TOOLS

Z_TOOLS Toolchain

Python tooling used to create, compare, convert, and install the icon/texture art mods.

Install

  • DOWNLOAD the ALL pack preset (uru 2x, runes 1x, artifacts 2x, baubles 2x, UI NoGlass, PowerNotReady)
  • OR choose specific packs between the 2x (80px) or original (40px) sizes (or create your own using the mod_selector tool)

Install the .zip with the MHO Extended Mod Manager (or the Krisan Thyme ModManager): click Install Mod..., select the zip, check the mod ON, click the Apply Changes button.
